## 中俄互助

- 中国与俄罗斯均存在、中国为独立国家、双方关系 ≥40 且中国不在战争中时，中国日志激活并触发邀请事件。
- 中国邀请俄罗斯，创建由工会和知识分子参与的亲俄游说团。
- 俄罗斯同意后，双方关系 +50，签订约束期 25 年的条约，包含同盟和双向贸易特权，并创建亲华游说团。
- 俄罗斯为独立国家且同意邀请后，俄罗斯日志激活。
- 日志激活期间提供：公司上限 +1、采矿业吞吐量 +20%、工会支持度 +5。中国侧在自身日志激活时即配置该加成。
- 当前脚本的失败条件为任一国家消失或中俄交战，尚未包含单独解除同盟的检查。
